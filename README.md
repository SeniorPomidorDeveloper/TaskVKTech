# TaskVKTech

Библиотека предназначен для отслеживания метрик.

## Описание

Библиотека содержит класса для отслеживания и записи метрик в файл.

Основные классы:

* `IEvent` - интерфейс для создания пользовательских событий.
* `SetEvent` - класс созданный для простого отслеживания метрик без дополнительных действий и передечи классу `Metric`.
* `IMetric` - интерфейс для работы с метриками. Класс нужен для исспользования метрик не задумываясь о типе значений которыые они принимают от класса `IEvent`.
* `Metrica` - класс запрашивает значение метрику у класса `SetEvent` ипроизводит форматирование полученного значения после чего передаёт это значение в класс `MetricManager`.
* `MetricMenager` - класс созданный для записи большого кол-ва метрик файл, через равные промежутки времени.

Билиотека включает в себя 2 примера исспользования:

1. Демонстрирует работу с библиотекой при встроенных типах.
2. Демонстрирует работу с библиотекой при пользовательских типах.

Также библиотека включает в себя набор тестов написанных с использованием библиотеки [Gtest](https://github.com/google/googletest).

## Сборка

Создание директории сборки и конфигурация проекта

```
# Базовая конфигурация (Debug с тестами)
cmake -B build -DCMAKE_BUILD_TYPE=Debug

# Конфигурация без тестов
cmake -B build -DBUILD_TESTS=OFF

# Конфигурация без примеров
cmake -B build -DBUILD_EXAMPLES=OFF

# Release сборка
cmake -B build -DCMAKE_BUILD_TYPE=Release
```

### Сборка проекта

```
cmake --build build --parallel
```

### Запуск тестов

```
cd build
ctest --verbose

# Или для запуска конкретного теста
./tests/SetEventTest
```

### Запуск примеров

```
# Пример 1
./build/examples/example1

# Пример 2
./build/examples/example2
```

### Дополнительные опции сборки

| Опция CMake | Значение по умолчанию | Описание                               |
| ---------------- | ---------------------------------------- | ---------------------------------------------- |
| BUILD_TESTS      | ON                                       | Включить сборку тестов     |
| BUILD_EXAMPLES   | ON                                       | Включить сборку примеров |
| CMAKE_BUILD_TYPE | Debug                                    | Тип сборки (Debug/Release)            |

Примеры использования:

```
# Сборка в Release режиме без тестов
cmake -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTS=OFF

# Сборка в Debug режиме без примеров
cmake -B build -DBUILD_EXAMPLES=OFF
```
